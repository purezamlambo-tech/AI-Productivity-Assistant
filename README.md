# AI Productivity Assistant

An interactive workplace automation tool developed by **Mornia Monareng**. Built using HTML5, Tailwind CSS, and JavaScript to automate routine workplace procedures including email generation, meeting summarization, task planning, research synthesis, and IT helpdesk support.

---

## 🌟 Core Features

* **✉️ Email Generation:** Converts key points into professional workplace correspondence.
* **📋 Meeting Summarization:** Extracts action items and key decisions from raw meeting notes.
* **📅 Daily Task Planning:** Prioritizes daily workloads into clear priority levels.
* **🔍 Research Assistance:** Generates structured research overviews for technical and operational topics.
* **🤖 IT Support Chatbot:** Provides step-by-step diagnostic workflows for helpdesk requests.

---

## 🛠️ Built With

* **Frontend:** HTML5 & Tailwind CSS
* **Logic:** JavaScript (ES6+)
* **Hosting & Source Control:** GitHub / Vercel

---

## 💡 Prompt Engineering Approach

1. **System Personas:** Tailored outputs for IT support, administrative management, and field operations.
2. **Contextual Injection:** Integrates relevant background operational details into final responses.
3. **Structured Outputs:** Formats responses into clean lists, email templates, and step-by-step guides.

---

## 🛡️ Responsible & Ethical AI Practices

* **Data Privacy:** Client-side execution ensures user prompts remain private.
* **Human-in-the-Loop:** All generated content serves as a baseline draft subject to human verification before deployment.
